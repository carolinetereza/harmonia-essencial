Website de alta autoridade para instituto médico estético com ticket médio de R$20.000+. Design editorial de luxo silencioso, sem qualquer elemento promocional ou estética de clínica popular.

---

### Design System

- **Paleta**: Warm Deep Brown (#2C1F1A), Taupe/Fendi (#9A8A7D), Soft Nude (#D6C2B3), Ivory (#F6F2EC), Branco Puro, Preto
- **Tipografia**: Playfair Display para títulos (serifa elegante), Inter para corpo (sans-serif refinada)
- **Texturas**: Grain overlay sutil, gradientes suaves de luz quente
- **Espaçamento**: Generoso whitespace editorial com layout luxuoso
- **Animações**: Scroll suave com fade-in, parallax sutil, hover elegante com blur/transparência — zero agressividade visual
